How a lesson flows
  1. Listen to the dialogue slowly, word by word, then at speed.
  2. Shadow each line: play, record, compare.
  3. Run the substitution drills from the book, speaking each answer before you see it.
  4. Rate yourself. Weak patterns come back first next time.
